## Acceptance criteria

- sqlc has operations to create a pending row, get one by ID and user, list direct children, and resolve an object by bucket/name.
- Completion updates authoritative object metadata and only accepts a generation that is not older than the stored generation.
- Duplicate completion events produce a deterministic no-op or the same resulting row.
- Nullable UUID, text, integer, and timestamp fields map correctly between pgx/sqlc and domain-owned values.
- The repository returns domain errors rather than leaking `pgx.ErrNoRows`.
